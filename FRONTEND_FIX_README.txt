KHAZAR LEAGUE - FRONTEND BLANK SCREEN FIX

This update normalizes public overview and fan API array fields before rendering.
It does not modify tournament data, player data, team data, or logo files.

INSTALL:
1. Stop the running local Khazar League windows.
2. Extract this ZIP into C:\KhazarLeague and choose Replace files when prompted.
3. Keep your existing .env file; this archive intentionally does not include .env.
4. Run START_KHAZAR_LEAGUE.bat again. It rebuilds the frontend before starting.
5. Open http://localhost:4173 and hard-refresh with Ctrl+F5.

Do not delete data/ or uploads/.
