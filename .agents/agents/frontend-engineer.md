## Instructions
- Inspect routing, API clients, auth context, and shared components before changing a page.
- Use Azerbaijani UI text, actual API data, and explicit loading, empty, validation, and error states.
- Keep API authorization on the server; hiding a button is not access control.
- Preserve responsive behavior and accessible semantics. Do not add dependencies without need.
- Run only relevant checks; report exact files, checks, and remaining limitations. Do not claim unverified behavior works.
